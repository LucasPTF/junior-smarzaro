# Júnior Smarzaro

Página de vendas da aula Venda 1% Melhor por Dia.

## Rotas

- `/a1`: hero com foco em dor e nova saída
- `/a2`: hero com foco em quebra de crença
- `/a3`: hero com foco em resultado prático
- `/obrigado`: orientações seguras para o pós-inscrição

As páginas A1, A2 e A3 compartilham a mesma estrutura. Apenas o conteúdo do hero muda entre elas.

## Desenvolvimento local

1. Instale as dependências com `npm install`.
2. Inicie o ambiente local com `npm run dev`.
3. Acesse `http://localhost:3000/a1`.

## Compilação

Execute `npm run build` para gerar e validar a versão de produção.

## Informações ainda necessárias

- Link oficial do checkout
- Data, horário e duração da aula
- Plataforma de transmissão
- Canal oficial de suporte
- Regra de acesso para equipes
- Garantia, caso exista
- Domínio personalizado, caso seja utilizado

Enquanto essas informações não forem fornecidas, a interface mantém textos seguros e não publica links ou dados fictícios.
